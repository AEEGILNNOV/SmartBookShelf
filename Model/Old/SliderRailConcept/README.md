# SliderRailConcept · 丝杠滑台 + 线轨 机械概念模型

依据《"速定位书格"智能图书存取系统项目说明书》+ 手绘草图 + 提示词，
用 Blender Python API（bpy）建立的**两个独立机械组件**概念模型：

| 组件 | 英文名 | 内容 |
| --- | --- | --- |
| 丝杠滑台 | `Slider_Assembly` | 42 步进电机 → 联轴器 → 丝杠 → 滑块（+ 顶部轴承座） |
| 线轨 | `Linear_Rail_Assembly` | 900 mm 导轨本体 + 套装式导轨滑块 |

- **零动画**：无关键帧、无时间轴、无动画导出，单帧定格。
- **不做**：柜体、书本、推书机构（按提示词要求排除）。
- **单位**：1 个 Blender 单位 = 1 mm，`unit_settings.scale_length = 0.001`。
- **防穿模**：脚本内建**双闸门 + 46 项设计断言**，任一不合格即打印具体数值并以
  非零退出码**终止构建**，绝不输出穿模模型。

## 3. 坐标与单位

| 项 | 值 |
| --- | --- |
| 单位系统 | 米，Unit Scale = 0.001（1 Blender 单位 = 1 mm） |
| X 轴 | 左右方向 |
| Y 轴 | 深度方向 |
| Z 轴 | 高度方向（+Z 上） |
| 组件原点 | **各自组件的最底部中心**（本地 (0,0,0)），世界位置由父级空物体携带 |
| `Empty_Slider_Axis` | 世界 (-100, 0, 0) mm —— 与提示词完全一致 |
| `Empty_Rail_Axis` | 世界 (+100, -1500, 0) mm —— X 与提示词一致，Y 为提示词要求的「错开」 |

每个零件的网格顶点都存放在**组件本地坐标系**里，父级空物体承载世界位置。
因此取消父级、或直接移动空物体，就能整体搬运 / 复用该组件。

## 4. 结构树与对象命名

```
Empty_Slider_Axis                                  world (-100, 0, 0)
├─ COL-01-A_Motor        GEO_Slider_Motor42        42x42x38 黑色本体 + 银色出轴 + 4 颗面板螺钉
├─ COL-01-B_Coupling     GEO_Slider_Coupling       Ø15x25 银色 + 2 颗径向紧定螺钉
├─ COL-01-C_LeadScrew    GEO_Slider_LeadScrew      Ø12 梯形螺纹丝杆（真实螺旋几何）
├─ COL-01-D_SliderBlock  GEO_Slider_Block          80x80x25 亮银滑块 + Ø40 螺纹孔凸台 + 4 颗内六角
└─ COL-01-E_TopBearing   GEO_Slider_TopBearing     44x44x24 丝杆顶部支撑座 + 4 颗螺钉

Empty_Rail_Axis                                    world (100, -1500, 0)
├─ COL-02-A_RailBody     GEO_Rail_Body             900x40x15 导轨 + 2 条滚道槽 + 15 个沉头安装孔
└─ COL-02-B_RailCarriage GEO_Rail_Carriage         60x40x30 套装式滑块 + 4 个沉头孔

COL-90_RenderStage                                 摄影棚（地面 / 背板 / 三点光 / 相机，不进入 GLB）
```

> **一个命名零件 = 一个网格物体 + 多个材质槽。**
> 电机本体与它的出轴、螺钉同属 `GEO_Slider_Motor42` 一个物体，
> 因此螺栓头与它坐落的平面之间不需要伪造 0 mm 空气间隙，
> 防穿模闸门看到的也是 7 个语义明确、互不重叠的实体。

命名规则：`GEO_<组件>_<零件>`，每个网格带 `dsh_group`
（刚体分组，防穿模按它配对）与 `dsh_part`（逻辑零件名）两个自定义属性。

## 6. 提示词冲突与裁定

提示词要求「以提示词为准，有冲突先参考提示词」。逐条核对后有 **2 处提示词内部
无法同时满足**的硬约束，处理如下：

| # | 冲突 | 提示词两种说法 | 裁定 | 理由 |
| --- | --- | --- | --- | --- |
| C1 | 丝杆长度 vs 组件包络 | 丝杆「长度 900」**且**「组件整体底部 Z=0、顶部 Z=900」 | **保包络 900**，丝杆毛坯取 843.5 | 电机 38 + 间隙 2 + 联轴器 25 与丝杆同轴串联：38+2+25+900 = 965 ≠ 900，二者数学上不可同时成立。包络 900 被写了两次、且是「两个组件高度与行程完全一致」的接口基准，故保包络；丝杆**螺纹外径仍为 Ø12**、**顶端仍精确落在 Z = 900**。 |
| C2 | 摆放 | 「在 Y 轴方向上错开摆放」**且** 两个组件都写「Y = 0」 | **X 保持 ∓100**，Y 按句意错开 -1500 | 两句话自相矛盾：若 Y 都为 0，则「错开」一句完全无意义。且 900 mm 高的细长件在 16:9 画幅里只占约 14% 宽度，两个组件会挤成中间两根细杆。X 是「左侧 / 右侧」的定义，保持与提示词完全一致；滑台 Y=0 也与提示词一致。<br>**改回字面 Y=0**：把 `P['WORLD_RAIL_Y'] = 0.0` 即可，其余全部自动跟随。 |

其他已按提示词直接满足的项：电机 / 联轴器 / 丝杆 / 滑块严格同轴；组件底部 Z = 0；
两个组件包络完全相同（0…900）；仅渲染 1 张 1920×1080；无动画；不含柜体 / 书本 / 推书机构。

> **额外补充件**：丝杆顶部轴承座（`GEO_Slider_TopBearing`）不在提示词的
> 4 个零件清单里，是丝杠滑台的标准附件 —— 给 843.5 mm 悬伸丝杆一个上端支承，
> 也让画面顶端有收束。不需要时把 `P['TOP_SUPPORT'] = False` 即可移除。

## 7. 防穿模校验（脚本内建三道闸门）

**GATE 1 · 包围盒安全网**（`clash.run_gates`）
按 `dsh_group` 逐对计算**顶点级世界 AABB**（不使用 `obj.bound_box` ——
后者在同一脚本内新建并移动对象后不刷新，会让校验形同虚设）。
非「已声明配合」的零件对必须满足 ≥ 2 mm。
AABB 间距取**逐轴间隙的欧氏距离**，而不是逐轴间隙的最小值 ——
后者会把「X 方向相距 600 mm、Z 方向重叠」的零件误判为穿模。

**GATE 2 · 网格级互穿检测**（更强的一关）
对**每一对**零件做世界空间 BVH 三角形相交测试。丝杆允许穿过螺母的包围盒，
但绝不允许与螺母共享实体体积；这一关就是证明这件事的。

**GATE 3 · 46 项设计断言**
所有尺寸都从**建好的几何**量回来，而不是相信参数表：
电机 42×42×38、轴 Ø8 伸出 15、联轴器 Ø15×25 且与电机面留 2 mm、
丝杆螺纹外径 Ø12、滑块 / 导轨 / 导轨滑块三向尺寸、两个组件包络 0…900 完全一致、
同轴度、空物体世界坐标、父子关系、无动画。

任一不合格 → 打印 ``` ANTI-CLASH GATE FAILED``` /
``` DESIGN ASSERTIONS FAILED``` 与具体数值，退出码 2，**不写任何文件**。

## 9. 参数化调整

所有尺寸集中在 `scripts/config.py` 的字典 `P`，`derive()` 自动推导派生值。
常用项：

```python
P['WORLD_RAIL_Y']  = 0.0       # C2：改回提示词字面的 Y = 0 布局
P['TOP_SUPPORT']   = False     # 去掉顶部轴承座
P['SCREW_PITCH']   = 4.0       # 丝杆螺距
P['BLOCK_CZ']      = 500.0     # 滑块中心高度（基准）
P['CARR_CZ']       = 500.0     # 导轨滑块中心高度
P['MIN_CLEARANCE'] = 2.0       # 全局最小安全间隙
P['CAM_AZ'], P['CAM_EL']       # 相机方位角 / 仰角
```

改完直接重跑，三道闸门会立刻告诉你新参数是否安全。

## 10. 视口裁剪（拉远即黑屏）

本模型 **1 Blender 单位 = 1 mm**，整机高 900 单位，而 Blender 出厂视口
`clip_end = 1000`。拉远视图时模型会被远裁剪面整片切掉，看起来就是**黑屏**。

`build.py` 在**写盘之前**调用 `stage.fix_viewport_clip()`，
把所有 3D 视口设为 `clip_start = 1` / `clip_end = 400000`，
并把每个相机数据的裁剪范围一并抬高（渲染后再调用一次并二次存盘，确保落到文件里）。

手动方式：视图 → 侧栏(N) → 视图 → 把**裁剪终点**设大（例如 400000）。

## 11. 与过去两个失败项目的关系

`MechanicalConcept`（第一版，不透明柜体 → 机构完全看不见）与
`ElevatorClampConcept`（第二版，亚克力柜体 → 机构仍难辨认）的问题，
本版逐条纠正：

| 过去的问题 | 本版做法 |
| --- | --- |
| 校验通过但图里看不出机构 | **只交付两个组件本体**，不含柜体遮挡；另出正交三视图与关节特写逐张目视核查 |
| 包围盒校验形同虚设（`obj.bound_box` 不刷新） | 改用**顶点级世界 AABB**，并追加 **BVH 三角形互穿测试**作为第二道闸门 |
| 布尔运算破坏几何（本次实测：出轴被整根删掉、滑块宽度 80 → 64.9） | 布尔求解器开 `use_self`，并新增专门的断言把每个尺寸从几何量回来 |
| 配合件（丝杆穿螺母）被误判穿模 | 显式声明 **MATE 对**并说明理由；MATE 对免 AABB 检查、但必须通过网格级互穿检查 |
| 1 BU = 1 mm 导致视口拉远黑屏 | 存盘前修正 `clip_start` / `clip_end`（见第 10 节） |
| 细长件在 16:9 里只占 14% 宽度 | 相机方位角与组件错开量**联立求解**（见 C2），使两个组件在画幅里占到约 50% 宽度 |

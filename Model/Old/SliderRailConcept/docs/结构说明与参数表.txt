〇、核心机械原理（不得更改）
------------------------------------------------------------------------------
  1. 书全部水平平躺，叠放在一个可升降的平台上。
  2. 移动的是「书 + 承载书的升降平台」，不是推出机构。
  3. 推出机构位置固定，推出孔位置固定。
  4. 中间夹层上下移动，改变推出孔的有效高度，以适配不同厚度的书。
  5. 全机只有 3 台 42 步进电机，全部采用丝杆传动。

一、运动链（三台电机分工）
------------------------------------------------------------------------------
  电机1 Motor01_Push_42
      子系统：固定推出机构
      安装：  固定于柜体后部
      传动：  42步进电机 → 联轴器 → 水平 T8 丝杆 → 丝杆螺母 → 推出小车 → 推书板
      作用：  推书板沿 Y 前后移动，把已到位的目标书从推出孔推出柜体；电机与丝杆自身不动

  电机2 Motor02_GapAdjust_42
      子系统：推出孔厚度调节
      安装：  固定于前面板内侧上方
      传动：  42步进电机 → 联轴器 → 垂直 T8 丝杆 → 丝杆螺母 → 可调中间夹层
      作用：  中间夹层沿 Z 上下移动，改变前面板推出孔的有效高度；推出机构完全不动

  电机3 Motor03_Lift_42
      子系统：书籍升降平台
      安装：  固定于柜体底部
      传动：  42步进电机 → 联轴器 → 垂直 T8 丝杆 → 丝杆螺母 → 升降平台 → 书籍堆
      作用：  平台带整摞书沿 Z 升降，把目标书送到固定推出位；平台不水平移动、不旋转

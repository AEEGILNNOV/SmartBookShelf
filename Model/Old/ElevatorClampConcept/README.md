# 速定位书格 · 机械概念模型（选项 A：电梯式夹取）

依据《“速定位书格”智能图书存取系统项目说明书》、手绘草图与提示词中的
**选项 A：电梯式夹取** 方案，用 Blender Python API 建立的可参数化机械概念模型。

- **零动画**：无关键帧、无时间轴、无动画导出，整机定格在「推书瞬间」。
- **单位**：1 个 Blender 单位 = 1 mm，`unit_settings.scale_length = 0.001`
  （真实尺度即米，整机 1.2 m 高）。坐标系 X = 宽、Y = 深（+Y 为正面）、
  Z = 高，原点在**整机底部中心**。
- **防穿模**：脚本内置三道包围盒校验闸门，任一不合格即打印警告并**终止构建**。

## 3. 机械原理（选项 A：电梯式夹取）

```
                 顶部放书孔 250 x 80（书竖着插入后平躺落到平台上）
        ┌───────────────────────────────┐  Z = 1200
        │                               │
        │   左丝杆(平台驱动)   右丝杆(限位板驱动) │
        │   右线轨(平台从动)   左线轨(限位板从动) │
        │                               │
        │        ┌──────────────┐       │
        │        │  限位板(底面橡胶垫) │      │  Z = 642  ← 抬起留出推杆通道
        │        ├──────────────┤       │
        │        │   书本(平躺)   │◄── 推书板 150x80x5   Z = 600
        │        ├──────────────┤       │
        │        │  移动平台(L型) │       │  Z = 580（顶面）
        │        └──────────────┘       │
  正面三层板 ──► │      中层全开口 = 推书口       │
        │        ╲ 30° 取书滑道 280x200   │  Z = 540
        └───────────────────────────────┘  Z = 0
```

三个 42 步进电机的分工：

| 电机 | 安装 | 驱动 | 从动支撑 |
| --- | --- | --- | --- |
| **电机 1** | 左侧丝杆最底部（垂直） | 移动平台升降 | 右线轨 + 滑块 |
| **电机 2** | 右侧丝杆最底部（垂直） | 限位板升降 | 左线轨 + 滑块 |
| **电机 3** | 后侧壁内表面（水平，Z = 600） | 推杆 + 推书板 | — |

工作循环：平台与限位板**差动升降**把书夹在中间 → 运送到固定推书口高度
Z = 600 → 限位板抬起留出空间 → 背部推杆伸出，推书板把书从正面推书口推入
30° 取书滑道。

## 4. 冻结姿态（推书瞬间）

| 项目 | 数值 |
| --- | --- |
| 平台顶面 | Z = 580 mm |
| 书本 | Z = 580 → 620 mm（平躺，书脊朝后 −Y，书页朝前 +Y） |
| 限位板橡胶垫底面 | Z = 642 mm（与书顶面留 22 mm 通道） |
| 推杆轴心 | Z = 600 mm，露出长度 80 mm |
| 推书板 | 150 × 80 × 5 mm，正面恰好贴住书脊（Y = −50） |
| 平台最低极限 | Z = 150 mm（距底部 42 电机顶面 90 mm 尚有 60 mm 余量） |

> **关于“推书电机与推杆”的可视性**：推书板正面贴住书脊（Y = −50），
> 因此推杆、联轴器与电机在几何上必然位于**书本之后**。在冻结姿态下，
> 从任何正面 / 3/4 视角看，它们都会被书本与平台遮挡——这是该机构
> 本身决定的，不是建模遗漏。`renders/diag/02_left_ortho.png`（左视图）
> 与 `renders/diag/04_port_closeup.png` 专门用于核查这条背部推书链，
> 可见 42 电机 → 联轴器 → 露出 80 mm 的推杆 → 推书板 → 书脊 的完整链路。

## 6. 防穿模校验（脚本内建）

```
GATE-1 互穿闸门   不同功能组之间包围盒交集体积必须为 0（除已声明的螺栓连接）
GATE-2 安全间隙   推杆 / 推书板 / 平台 / 限位板 / 书本两两间距 >= 2 mm
GATE-3 姿态断言   平台顶面 580、书 580–620、垫底面 >= 640、推杆露出 80、
                  推书板 150x80x5、两滑台错开 >= 150、行程不撞底部电机
```

任一不通过都会打印 `WARNING` 与具体数值，并以退出码 1 **终止构建**，
提示需要调整参数，避免输出穿模的机构。

## 7. 提示词内部冲突的处理

提示词要求“以提示词为准”，但提示词内部存在三处互相矛盾的硬约束，
本项目按下述方式做了**最小改动**并在校验报告中显式记录：

| 冲突 | 原始要求 | 处理 | 理由 |
| --- | --- | --- | --- |
| 限位板底面 vs 推书板 | 垫底面 Z = 640，推书板 80 高、中心 Z = 600（顶面 640） | 垫底面抬到 **642**，保留 2 mm 间隙 | 防穿模是“务必”级硬约束；推书板尺寸与推杆中心高度保持不变 |
| 两滑台错开 | “错开至少 150 mm”但举例 580 / 640（仅 60） | 左滑块 **480**、右滑块 **640**，错开 **160 mm** | 满足规范性表述“>= 150 mm”；平台顶面仍为 580（靠 100 mm 支架抬升） |
| 顶部放书孔 | 孔 250 × 80，而平躺书最小投影 150 × 210 | 书**竖着由孔插入后平躺**落到平台 | 80 mm 宽槽口无法通过平躺书本，这是唯一自洽解释 |

此外，为使“背后固定高度的推书电机和伸出的推杆”在渲染中**可见**，
电机安装在后侧壁的**内表面**（仍属“固定在后侧壁”）；此时
“电机 + 联轴器 = 70 mm”与“推杆露出 80 mm”两条要求可同时满足。

## 8. 参数化调整

所有尺寸集中在 `scripts/params.py` 的字典 `P` 中，`derive()` 自动推导派生值：

```python
P['PORT_CZ'] = 600.0            # 固定推书口高度
P['PLAT_TOP_Z'] 见 derive()      # 平台顶面 580
P['PUSH_PLATE_W'], P['PUSH_PLATE_H'], P['PUSH_PLATE_T'] = 150.0, 80.0, 5.0
P['PUSH_STROKE'] = 80.0         # 推杆露出长度
P['PLATFORM_SLIDER_Z'] = 480.0  # 左滑块
P['LIMIT_SLIDER_Z'] = 640.0     # 右滑块
P['LIM_PAD_BOTTOM_Z'] = 640.0   # 会被 max() 自动抬到不与推书板干涉的值
P['MIN_CLEARANCE'] = 2.0        # 全局最小安全间隙
P['TOP_HOLE_W'], P['TOP_HOLE_D'] = 250.0, 80.0
```

把 `LIM_PAD_BOTTOM_Z` 改回 640 并同时把 `PUSH_PLATE_H` 改为 76，
即可在保持 640 的同时继续满足 2 mm 间隙。

## 9. 视口裁剪距离（拉远即黑屏）—— 已修复

本模型 **1 Blender 单位 = 1 mm**，整机高约 1214 单位，而 Blender 出厂
视口裁剪终点只有 `clip_end = 1000`。因此在视口里向外滚动缩放时，
模型会被远裁剪面整片切掉，看起来就是**黑屏 / 模型消失**。

**根因**：`build.py` 原先在 `save_blend()` **之后**才调用视口裁剪修正，
于是修正结果根本没写进文件——保存下来的 `.blend` 里 10 个 3D 视口
全部还是 `clip_start=0.0 / clip_end=1000`（已实测确认）。

**修复**：

1. `build.py` 现在在写盘**之前**调用 `scene_render.fix_viewport_clip()`，
   并把修补数量打印出来；
2. 该函数同时覆盖 `bpy.data.screens` 与窗口管理器里的屏幕，
   并把每个相机数据的 `clip_end` 一并抬高；
3. 新增 `scripts/fix_viewport_clip.py`，可直接修复任意已存文件
   （自动生成 `.preclip.bak` 备份，保存后**重新打开**并把读回值打印出来作证）。

修复后的持久值（实测读回）：

```
Layout/VIEW_3D            clip_start = 1.0   clip_end = 300000
（Animation / Modeling / Sculpting / Shading / UV Editing /
  Texture Paint / Geometry Nodes / Scripting 同样为 1 / 300000）
camera CAM_Preview_3Q     clip_start = 1.0   clip_end = 500000
```

单独修复某个已有 `.blend`：

```powershell
& "D:\Application\3D\Blender\blender.exe" --background --factory-startup `
  --python "scripts\fix_viewport_clip.py" -- "models\elevator_clamp_v01.blend"
```

手动方式：视图 → 侧栏(N) → 视图 → 把**裁剪终点**改大（例如 100000 mm）。

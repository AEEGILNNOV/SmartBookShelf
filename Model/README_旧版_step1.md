# 速定位书格 · 机械概念模型（Blender）

依据《"速定位书格"智能图书存取系统项目说明书》+ 手绘草图 + 提示词，
用 Blender Python API（bpy）建立的可参数化**机械结构概念模型**。

- **零动画**：无关键帧、无时间轴、无动画导出，整机定格在「推书瞬间」。
- **单位**：1 个 Blender 单位 = 1 mm，`unit_settings.scale_length = 0.001`
  （真实尺度即米，整机 1.2 m 高）。
  坐标系 **X = 宽**、**Y = 深（+Y 为正面）**、**Z = 高**，原点在**整机底部中心**。
- **防穿模**：脚本内建「包围盒安全网闸门 + 13 项设计断言」，任一不合格即
  打印具体数值并以非零退出码**终止构建**，绝不输出穿模模型。

> **本仓库当前完成到第 1 步。** 限位板（第 2 步）、背部推书链（用户要求缓做）、
> 取书滑道（第 3 步）尚未建模，但它们的空间已在参数表中**预留并校验**。

## 1. 快速开始

```powershell
# 第 1 步完整构建：模型 + 4 张图（约 1.5 分钟，EEVEE）
& "D:/Application/3D/Blender/blender.exe" --background --factory-startup `
    --python "scripts/build_step1.py"

# 快速迭代（960x540 / 32 采样）
... --python build_step1.py -- fast

# 只建模与校验，不渲染（约 3 秒，日常调参用这个）
... --python build_step1.py -- norender fast

# 用 Cycles 出高质量图（CPU 约 5-8 分钟）
... --python build_step1.py -- cycles

# 隐藏正面上下两块固定板，方便直接看内部机构
... --python build_step1.py -- openfront fast
```

脚本模块彼此独立，也可在 Blender 图形界面里直接打开 `scripts/build_step1.py` 运行。

## 3. 第 1 步建立的机构

```
                    顶部放书孔 250 x 170  (Z = 1200, 顶面板)
        ┌───────────────────────────────────────┐
        │  左丝杆(驱动平台)      右线轨(平台从动)   │
        │  右丝杆(驱动限位板)    左线轨(限位板从动) │
        │                                       │
        │           ┌───────────────┐           │
        │           │ 书本 210x185x40 │  Z 580-620 │  ← 平躺，书脊朝后(-Y)
        │           ├───────────────┤           │
        │           │ 移动平台 顶面580 │  L 型挡边 │  ← 左滑块 Z=480
        │           └───────────────┘           │
  ──────┤         中层全开口 = 推书口             ├──────
        │           (Z 520 - 680)               │
        │                                       │
        │  [42电机1]                 [42电机2]    │  ← 垂直，丝杆最底部
        └───────────────────────────────────────┘  Z = 0
```

| 部件 | 位置 | 尺寸 |
| --- | --- | --- |
| 柜体框架 | 600 × 450 × 1200，框架厚 20 | 4 立柱 + 上下板 + 三面亚克力壳 |
| 正面三层板 | 顶层固定 / **中层全开口** / 底层固定 | 开口 Z 520–680（中心 600） |
| 顶部放书孔 | 顶面中心 | 250 × 170（见冲突 4） |
| 左丝杆 | X = −215, Y = −175，Z 90–990 | 900 mm，螺距 4 mm 螺旋面 |
| 右从动线轨 | X = +215, Y = +215，Z 20–920 | 900 mm，20×20 |
| 42 电机 ×2 | 各自丝杆最底部，垂直 | 42 × 42 × 38 + 联轴器 = 70 |
| 移动平台 | 顶面 Z = 580，L 型挡边 10 mm | 424 × 220 托板 |
| 平台驱动滑块 | 左，Z = 480 | 80 × 80 |
| 平台从动滑块 | 右线轨上，Z = 480 | 80 × 80 |
| 书本 | 平躺 Z 580–620，书脊朝后 | 210 × 185 × 40 |

工作逻辑：平台与限位板**差动升降**把书夹在中间 → 运送到固定推书口高度
Z = 600 → 限位板抬起留出通道 → 背部推杆伸出，把书从正面推出口推出。

## 5. 防穿模校验（脚本内建两道闸门）

**闸门 1 · 包围盒安全网**（`sbs_clash.check`）
按 `dsh_group` 逐对测试跨刚体包围盒；同一刚体内部是已声明的刚性连接，
允许互穿；跨刚体必须满足 ≥ `MIN_CLEARANCE`（2 mm）。
包围盒用**网格顶点直接计算**，不使用 `obj.bound_box` ——
后者在同一脚本内新建并移动对象后不会刷新，会返回过期坐标让校验形同虚设。

**闸门 2 · 13 项设计断言**（`sbs_clash.assert_design`，真正吃重的一关）

| 编号 | 断言 | 第 1 步实测 |
| --- | --- | --- |
| A1a | 无任何平台件**穿入**驱动柱 | 0.000 mm（无穿模） |
| A1b | 最紧的非连接件对仍保有 ≥ 2 mm | 488.98 mm |
| A2 | 书本底面恰好落在平台顶面 | 0.000 mm |
| A3 | 书口到后挡边间隙 | 5.000 mm |
| A4 | 书本到左挡边间隙 | 97.000 mm |
| A5/A5b | 推书板相对书厚上下各外伸 20 mm（有意设计） | 20 / 20 mm |
| A6 | 推书板背面到后挡边 | 195.000 mm |
| A7 | **推书行程通道内无任何结构阻挡** | 0 个阻挡 |
| A8 | 左右滑台错开量 | 160 mm（≥ 150） |
| A9 | 电机 + 联轴器总高 | 70.0 mm |
| A10 | 平台最低点（Z=150）到联轴器顶 | 60.0 mm |
| A11 | 丝杆行程覆盖两个滑台 | 通过 |

任一不合格 → 打印 `!!! ANTI-CLASH GATE FAILED` / `DESIGN ASSERTION(S) FAILED`
与具体数值，退出码 2 或 3，**不写文件**。

## 6. 提示词与草图 / 说明书的冲突处理

提示词要求「以提示词为准，有冲突先参考提示词」。逐条核对后共发现 5 处
无法同时满足的硬约束，已与用户逐条确认并按其裁定执行：

| # | 冲突 | 提示词要求 | 用户裁定 | 理由 |
| --- | --- | --- | --- | --- |
| 1 | 平台高度 | 平台顶面 580 / 推书口 600 / 三层板中层 600 | **保持 580** | 与推书口、中层板三者自洽；若改 780 则推书板够不到书 |
| 2 | 限位板 vs 推书板 | 垫底面 640，推书板 80 高中心 600（顶边 = 640） | 垫底面抬到 **642** | 间隙 0 mm 即穿模，违反「务必防止穿模」；只挪 2 mm |
| 3 | 两滑台错开 | 「错开**至少 150**」但举例 580/640（仅 60） | 左 **480** / 右 **640** | 满足规范性表述「≥150」（错开 160）；平台靠支架抬到 580 |
| 4 | 顶部放书孔 | 250 × 80 | 扩为 **250 × 170** | 平躺书宽 150 mm，80 mm 槽口**几何上无法通过** |
| 5 | 推书电机 | 「固定在后侧壁」未说明内外 | 用户裁定**先不做** | 本轮先交付框架 + 平台 + 升降 |

其他已确认解读：书脊朝后（+Y 最大面）、书页朝前；左丝杆驱动平台 +
右线轨从动；右丝杆驱动限位板 + 左线轨从动；仅渲染 1 张 1920×1080 静态图。

`MechanicalConcept`（第一版）与 `ElevatorClampConcept`（第二版）的问题，
本版逐条纠正：

| 过去的问题 | 本版做法 |
| --- | --- |

## 8. 参数化调整

所有尺寸集中在 `scripts/sbs_params.py` 的字典 `P`，`derive()` 自动推导派生值。
常用项：

```python
P['CAB_W'], P['CAB_D'], P['CAB_H'] = 600.0, 450.0, 1200.0
P['PORT_CZ']            = 600.0    # 固定推书口中心高度
P['PLAT_TOP_Z']         = 580.0    # 平台顶面（冻结姿态）
P['PLATFORM_SLIDER_Z']  = 480.0    # 左滑块
P['LIMIT_SLIDER_Z']     = 640.0    # 右滑块（第 2 步用）
P['TOP_HOLE_W'], P['TOP_HOLE_D'] = 250.0, 170.0
P['BOOK_X'], P['BOOK_Y'], P['BOOK_T'] = 210.0, 185.0, 40.0
P['BOOK_SPINE_Y']       = -50.0    # 书脊平面，朝推杆侧
P['MIN_CLEARANCE']      = 2.0      # 全局最小安全间隙
P['LIM_PAD_BOTTOM_Z']   = 642.0    # 第 2 步限位板垫底面
```

改完直接重跑即可，两道闸门会立刻告诉你新参数是否安全。

## 9. 视口裁剪（拉远即黑屏）

本模型 **1 Blender 单位 = 1 mm**，整机高 1200 单位，而 Blender 出厂视口
`clip_end = 1000`。拉远视图时模型会被远裁剪面整片切掉，看起来就是**黑屏**。

`build_step1.py` 在**写盘之前**调用 `fix_viewport_clip()`，把所有 3D 视口
设为 `clip_start = 1` / `clip_end = 300000`，并把每个相机数据的裁剪范围一并抬高。

手动方式：视图 → 侧栏(N) → 视图 → 把**裁剪终点**设大（例如 300000）。

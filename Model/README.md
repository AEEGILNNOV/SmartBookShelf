# “速定位书格” 智能图书存取系统 · 机械结构工程模型（Blender）

依据**用户提示词（最高优先级）** + 原始实物照片 + 手绘草图 + 参考结构示意图 +
《“速定位书格”智能图书存取系统项目说明书》，用 Blender Python（bpy）建立的
**可参数化、可复现、带完整机械动画的工程化三维模型**。

## 2. 核心机械原理【不可更改】

**本设备不是机械臂，不是机械抓手，也不是多层书架逐层取书。**

整个设备内部主要存放的是**“一摞平躺的书”**，真正移动的是
**“书 + 承载书籍的升降平台”**，推出机构本身的位置固定不动。

| # | 规则 |
| - | - |
| 1 | 书全部水平平躺（封面朝上），多本上下叠放在**同一个升降平台**上 |
| 2 | 升降平台通过 T8 丝杆上下移动，**书随平台一起走** |
| 3 | 平台把目标书送到**高度固定**的推出位 |
| 4 | **位置固定**的推出机构把目标书向前推出柜体 |
| 5 | 前面板内部有一块可上下移动的**中间夹层**，它改变**推出孔的有效高度**，从而适配不同厚度的书 |

一句话：**「升降平台负责定位书的高度，中间夹层负责调节推出孔尺寸，固定推出机构负责把书推出。」**

## 3. 三台电机（严格只有 3 台，全部 42 步进 + 丝杆）

```
电机3  Motor03_Lift_42   固定于柜体底部
   42步进电机 → 联轴器 → 垂直 T8 丝杆 → 丝杆螺母 → 升降平台 → 书籍堆
   平台带整摞书沿 Z 升降；平台不水平移动、不旋转

电机1  Motor01_Push_42   固定于柜体后部（自身不随平台运动）
   42步进电机 → 联轴器 → 水平 T8 丝杆 → 丝杆螺母 → 推出小车 → 推书板
   推书板沿 Y 前后移动，把已到位的目标书从推出孔推出柜体

电机2  Motor02_GapAdjust_42  固定于前面板内侧上方
   42步进电机 → 联轴器 → 垂直 T8 丝杆 → 丝杆螺母 → 可调中间夹层
   中间夹层沿 Z 上下移动，改变前面板推出孔的有效高度；推出机构完全不动
```

三根丝杆均为 **T8（导程 4 mm）**，模型里是**真实螺旋梯形螺纹**（核心圆柱 + 螺旋扫掠），
不是贴图或圆环装饰。三根丝杆在动画中**按被驱动件的实际位移逐帧反解转角**，
螺纹旋转与直线运动严格同步。

**未使用** 28BYJ-48、舵机、机械臂、齿轮齿条、同步带。

## 4. 坐标系与单位

* **单位**：1 个 Blender 单位 = 1 mm，`unit_settings.scale_length = 0.001`
* **X** = 宽度（+X 右）　**Y** = 深度（**+Y 为柜体正面**）　**Z** = 高度（+Z 上）
* **原点** = 整机底面中心 (0, 0, 0)
* 整机外形 **600 × 350 × 700 mm**（与参考图标注的 宽600 / 深350 / 高700 一致）

```
        │        │  书 4  (厚 40)  Z 450–490 │           │
        │        │  书 3  (厚 30)  Z 410–450 │ ← 目标书   │
        │        │  书 2  (厚 25)  Z 385–410 │           │

        │        │      升降平台  X ±170      │           │
        │        └───────────────────────────┘           │
        │                     ↑ ↓ 行程 140 mm             │
        │═════════ 推出孔（可调 18–53 mm）════════════════│  Z 380–500
        │        →→→  推书板（固定在此高度）               │
        │  [电机1 固定推出机构]      [可调中间夹层 + 电机2] │
        │  底部电控区：驱动器 / 开关电源                    │
        └───────────────────────────────────────────────┘  Z = 0
```

| 项目 | 数值 | 说明 |
| --- | --- | --- |
| 整机外形 | 600 × 350 × 700 | 宽 × 深 × 高 |
| 柜体内腔 | 544 × 334 × 670 | 全部机构零件都在其中（断言 A20） |
| 书籍 | 5 本，180 × 150 × {15, 25, 30, 40, 50} | 全部水平平躺，总高 160 |
| 升降平台 | X ±170，顶面 Z 150–380 | 升程 140（动画 200→340） |
| 推出孔下沿 | **Z = 380（固定）** | 前面板下层的上缘 |
| 推出孔可调高度 | **18 – 53 mm** | 由中间夹层下沿决定 |
| 目标书 Book_03（厚 30）到位的推出孔 | **33 mm** | 书厚 + 3 mm 间隙 |
| 推书板 | 150 × 14 × 6 | **板高 14 ≤ 最薄书 15**，才能穿过推出孔只推一本 |
| 推书行程 | 132 mm | 螺母 −82 → +50 |
| 目标书推出位移 | 128 mm | 伸出柜体 37 mm |
| 升降丝杆 | T8，Z 83–408 | 下端由电机端承担，上端轴承座固定于背板 |

### 为什么推书板只有 14 mm 高？

推出孔的**下沿固定**在 Z = 380，而书随平台升降，所以**任何一本目标书的下沿都落在 380**。
推书板必须从 Z = 380 起、且不得高于最薄书（15 mm）的顶面，否则会撞到上方那本书。
因此推书板做成 **Z 380.5 – 394.5（高 14 mm）**，刚性横梁在其后方，由丝杆螺母 + 导轨滑块
组成的推出小车驱动。这也是「用可调推出孔对书做**单本分离（singulation）**」的关键：
中间夹层的下沿就是挡书的上边界，只有目标书那一层是通的。

## 7. 动画（提示词第 15 节，24 fps / 360 帧 / 14.96 秒）

| 时间 | 内容 |
| --- | --- |
| 0–2 s | 初始状态：一摞书水平平躺在升降平台上（平台顶面 Z 200） |
| 2–6 s | 电机3 工作，平台带整摞书上升 140 mm，Book_03 到达固定推出位并停止 |
| 6–7 s | 电机2 工作，中间夹层上移到最高位（推出孔 53 mm）——即校准动作 |
| 7–8 s | 中间夹层回落到目标位（推出孔 33 mm），对准 30 mm 厚的目标书 |
| 8–11 s | 电机1 工作，推书板前移，把 Book_03 从推出孔推出柜体 |
| 11–13 s | 推书板返回原位 |
| 13–15 s | 完成取书状态：书本留在柜外 |

运动关系全部用**真实父子关系 + 关键帧**实现（可直接导出到 glTF）：

* `LiftPlatform` 沿 Z 运动 → 其子级 `Books_Stack` → `Book_01..05` 随之升降
* `Push_Carriage` 沿 Y 运动 → 其子级 `Push_Carriage_Beam` / `Push_Plate` /
  `Push_ScrewNut` / `Push_Carriage_Slider` 一起前后移动
* `Middle_Layer` 沿 Z 运动，带动其子级滑块与调节螺母
* **Book_03 的 Y 逐帧由小车的实际位置反解**（`offset = max(0, nut_y − 接触点)`），
  保证书脊与推书板正面**始终严格贴合、零穿透、零脱节**
* 三根丝杆逐帧反解转角，T8 导程 4 mm，螺纹与直线运动同步

## 9. 与参考图 / 说明书 / 失败项目的关系

### 9.1 尺寸与方案冲突的处理

提示词要求「以提示词为准，有冲突先参考提示词」。逐条核对后的裁定：

| # | 冲突 | 前两版失败项目的做法 | 本版做法 |
| --- | --- | --- | --- |
| 1 | 整机尺寸 | 600 × **450** × **1200**（自定） | 严格按提示词 / 参考图：**600 × 350 × 700** |
| 2 | 取书原理 | 多层书架逐层取书 / 平台与限位板差动夹取 | **一摞平躺的书 + 升降平台 + 固定推出**，无书架分层 |
| 3 | 书厚适应 | 楔形斜块 + 独立限位挡板 | **中间夹层上下移动改变推出孔高度**（提示词第 7 节） |
| 4 | 电机数量与型号 | 2～3 台，论证阶段用 28BYJ | **固定 3 台 42 步进电机**，全部丝杆传动 |
| 5 | 推书板厚度 | 80 mm 高（无法穿过薄书推出孔） | **14 mm ≤ 最薄书 15 mm**，可穿过推出孔实现单本分离 |
| 6 | 深度受限（350 mm） | — | 电机1 / 联轴器 / 轴承座 / 丝杆 / 行程 / 书深重新分配，恰好装入 320 mm 内腔 |

### 9.2 从两版失败项目学到的、本版逐条纠正的问题

| 过去的问题 | 本版做法 |
| --- | --- |
| 机械原理被自行改错（多层书架 / 电梯夹取） | 原理锁定为提示词第一节，并用 26 条断言把原理**机器可验证** |
| 动画只做静态定格或干脆没有 | 完整 360 帧运动链动画 + 工序帧用于帧间一致性核查 |
| 校验通过但图里看不出机构 | 校验 = 顶点级世界包围盒 + 26 项设计断言 + **多帧**干涉扫描 |
| 包围盒校验形同虚设（合并对象 AABB 覆盖整个内腔） | 空心外壳标记为 `envelope` 不参与两两判定，另加 A20 内腔包容断言；组合件尽量拆成独立对象 |
| 亚克力不透明 / 内部看不清 | 侧面为白框 + 亚克力视窗（transmission 0.92），VIEW 2/3 直接剖开 |
| 1 BU = 1 mm 导致拉远黑屏 | 存盘前统一修正视口与相机裁剪（clip_end = 4×10⁵ mm） |
| 相机取景裁切 / 主体过小 | 由垂直 FOV **反解相机距离**；VIEW 9 用正交版面反解 ortho_scale |
| 中文标注无法渲染 | 加载系统 SimHei 字体，并把标注放在相机坐标系里（不镜像、不越界） |
| Blender 5.x 视频导出失败 | 用 `media_type='VIDEO'` 解锁 FFMPEG 后再设 `file_format='FFMPEG'` |

## 10. 自动校验（`build\sbs_validate.py`）

### 闸门 1 · 跨刚体包围盒干涉

按 `grp`（刚体分组）两两测试**世界空间顶点 AABB**；同一 `kin`（运动副）标记的零件对豁免——
因为丝杆必然穿在螺母里、导轨必然穿在滑块里。在 **9 个关键帧**（1 / 96 / 144 / 180 / 192 /
220 / 264 / 300 / 360）逐帧扫描，任一帧出现相交体积 > 1 mm³ 即判定失败。

当前结果：**0 处干涉**（报告里的「最小间隙 0.0 mm」只出现在「电机1 安装座贴合背板」
这类零体积的面对面接触上）。

## 12. 参数化调整

所有尺寸集中在 `build/sbs_params.py` 的字典 `P` 中，`derive()` 自动推导派生值并在导入时
自检几何自洽性（推出孔必须能通过最厚书、推书板不得高于最薄书顶面、中间夹层必须遮住开口…）。
常用项：

```python
P['CAB_W'], P['CAB_D'], P['CAB_H'] = 600.0, 350.0, 700.0
P['PORT_Z0']        = 380.0    # 推出孔下沿（固定）
P['GAP_BOT_MIN']    = 398.0    # 中间夹层最低位 → 推出孔 18 mm
P['GAP_BOT_MAX']    = 433.0    # 中间夹层最高位 → 推出孔 53 mm
P['GAP_BOT_TARGET'] = 413.0    # 30 mm 目标书 → 推出孔 33 mm
P['PUSH_NUT_Y_RET'] = -82.0    # 推出小车退回位
P['PUSH_NUT_Y_EXT'] = 50.0     # 推出小车推出位
P['BOOK_T']         = [15.0, 25.0, 30.0, 40.0, 50.0]
P['MIN_CLEARANCE']  = 1.0      # 全局最小安全间隙 mm
```

改完直接重跑 `build anim explode stage validate`，两道闸门会立刻告诉你新参数是否安全。
